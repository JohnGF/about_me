Guide to the Included Literature

This literature package contains three fundamental papers spanning neuroanatomy, signal processing, and interactive virtual paradigms. Click to expand the summaries and key BCI relevance below:

  1. Lécuyer et al. (2008) — Brain-Computer Interfaces, Virtual Reality, and Videogames

    Reveal Takeaways & BCI Relevance
    • Core Focus: Navigating the intersection of BCI signal acquisition and real-time virtual environment (VE) feedback.
    • Key Takeaways:
      • Proves that highly immersive and interactive VR setups increase user motivation, shorten BCI calibration training, and improve signal classification rates compared to generic 2D monitors.
      • Highlights landmark BCI game architectures, such as the MindBalance tightrope-walker game (using visual attention to two SSVEP checkerboards phase-reversed at 17 Hz and 20 Hz).
      • Outlines design guidelines for mapping discrete BCI classifications to game commands (e.g. camera navigation, object manipulation).

  2. Lotte (2014) — A Tutorial on EEG Signal-processing Techniques for Mental-state Recognition in Brain–Computer Interfaces

    Reveal Takeaways & BCI Relevance
    • Core Focus: An introductory math and engineering tutorial detailing the BCI classification pipeline (spatial filtering, band power extraction, and classification).
    • Key Takeaways:
      • Explains the mathematical motivation for spatial filtering (e.g. Laplacian, Bipolar, or CSP) to mitigate spatial blurring and the low SNR of raw scalp EEG.
      • Details why BCI setups require a two-phase loop: a calibration/training phase to tune weights and thresholds using labeled data, followed by an online test/use phase.
      • Defines the standard feature extraction method: calculating band power in the (8-12 Hz) and (16-24 Hz) ranges over the motor cortex (C3/C4) and classifying it using Linear Discriminant Analysis (LDA).

  3. Grèzes & Decety (2001) — Functional anatomy of execution, mental simulation, observation, and verb generation of actions: A meta-analysis

    Reveal Takeaways & BCI Relevance
    • Core Focus: A structural and functional mapping of shared motor representations in the human brain during physical execution and mental simulation (motor imagery).
    • Key Takeaways:
      • Confirms a structural overlap in the cortical networks engaged in action execution and mental simulation (motor imagery), including the primary motor cortex (M1), dorsal/ventral premotor cortex, and SMA.
      • Hand motor imagery specifically drives focal activations in the sensorimotor cortex hand representation area (approximately to , to ).
      • Provides the neuroanatomical foundation for targeting (left hemisphere) and (right hemisphere) scalp electrode locations to capture contralateral SMR desynchronization during imagined right/left hand movements.

Core Experiment / Game Loop setup

Trial Paradigm

This loop runs deterministically to capture Event-Related Desynchronization (ERD) without cognitive adaptation.

Phase Duration LSL Marker Paradigm / Neurofeedback Mechanics
1. Fixation/Rest 2.0 – 3.0s (Jittered) 10 Establishes running baseline power spectral density (PSD). Pre-stimulus focus.
2. Cue/Stimulus 1.0s 20 Visual target lane/auditory prompt appears. No motor imagery yet.
3. Rhythmic Task 3.0 – 4.0s 30 Active SMR/Motor Imagery. User syncs intent with target rhythm.
4. Feedback 1.5s 40 Closed-loop visual cue adjustment or HRTF audio attenuation update.

using System.Collections;
using UnityEngine;
using LSL;

public class UnityParadigmMarkerOutlet : MonoBehaviour
{
    private StreamOutlet outlet;
    private string[] currentSample = new string[1]; // LSL expects samples as arrays

    void Start()
    {
        // Define marker stream meta-data
        StreamInfo streamInfo = new StreamInfo(
            "UnityParadigmMarkers", // Stream Name
            "Markers",              // Stream Type (Critical for discovery)
            1,                      // Channel Count
            0,                      // Irregular/Event-driven sampling rate
            channel_format_t.cf_string, 
            "UnityVR_RhythmRPG_001" // Unique Source ID
        );

        outlet = new StreamOutlet(streamInfo);
    }

    // Call this method to kick off a trial loop block
    public void StartNewTrial()
    {
        StartCoroutine(TrialRoutine());
    }

    private IEnumerator TrialRoutine()
    {
        // Phase 1: Fixation / Rest (with 2.0s to 3.0s jitter)
        SendMarker("10_REST_START");
        yield return new WaitForSeconds(Random.Range(2.0f, 3.0f));

        // Phase 2: Cue / Stimulus Onset (1.0s)
        SendMarker("20_CUE_ONSET");
        yield return new WaitForSeconds(1.0f);

        // Phase 3: Active Rhythmic Task Execution (3.5s)
        SendMarker("30_TASK_START");
        yield return new WaitForSeconds(3.5f);

        // Phase 4: Feedback Window Display (1.5s)
        SendMarker("40_FEEDBACK_START");
        yield return new WaitForSeconds(1.5f);

        SendMarker("00_TRIAL_END");
    }

    private void SendMarker(string markerValue)
    {
        currentSample[0] = markerValue;
        // Pushes the string marker immediately into the local network with local clock timestamp
        outlet.push_sample(currentSample); 
        Debug.Log($"[LSL Sent]: {markerValue}");
    }
}

Verification & Local Testing

Before attempting to stream live data from an amplifier, you must verify your algorithmic logic offline using synthetic data. A mock EEG data generator has been provided in the repository.

Running Local Tests
  1. Locate the test harness file: tests/test_pipeline.py
  2. Uncomment your class instantiations inside the test_pipeline_contracts() function.
  3. Run the script from your terminal: 
    python tests/test_pipeline.py
  4. If your temporal or spatial math violates the matrix shapes or introduces NaNs, the execution will trip the contract assert statements and fail immediately. Your track is complete when this script runs with zero errors.
